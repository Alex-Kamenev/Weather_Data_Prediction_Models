# New York weather prediction models

Academic experiments using the cleaned 2015–2020 weather observations: regression, classification, and autoregressive time-series forecasting. The included `edapy` package supports preparation and visualization, and `model_predict_py` contains reusable model helpers.

Use Python 3.12 and run from the repository root:

```text
python -m venv .venv
```

Activate the environment (`.venv\Scripts\Activate.ps1` in PowerShell), then:

```text
python -m pip install -r requirements.txt
python -m notebook Classification_Weather_Data.ipynb
python -m unittest discover -s tests
```

The classifier uses `data/weather_data_for_classifier.csv`. Regression and forecasting use `data/clean_weather_data.csv` through `Weather_Data_Predictive_Models.ipynb`.

The forecasting notebook uses the historical `ForecasterAutoreg` and grid-search API. For that notebook, create a **separate environment** and install `requirements-forecasting.txt`; it selects the compatible skforecast 0.13 API. See the [skforecast migration guide](https://skforecast.org/latest/user_guides/migration-guide) before upgrading that experiment. Ordinary model helpers do not import this optional dependency.

Regression helpers use a seeded random holdout. This is an exploratory validation choice, not a substitute for chronological validation of future forecasts. Grid searches are large and expensive; stored notebook results have not been regenerated by the maintenance checks. The source helper tests cover missing-value preservation and duplicate-index encoding; they do not certify the models' scientific conclusions.
